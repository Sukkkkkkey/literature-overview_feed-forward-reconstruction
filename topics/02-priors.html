01 / QUESTION模型给出了米，图像就提供了米吗？

单张图像能提供透视、遮挡、纹理梯度和物体语义，却通常不能唯一确定绝对尺度。把一间房及相机位置同时放大，投影图像可以完全相同。因此本章区分三类能力：从数据学到的尺度先验、由多视视差约束的相对形状，以及由真实尺度测量确定的 metric 几何。

阅读单目模型时，先问输出是 inverse depth、z-depth、相机系点图还是射线距离；再问评测允许 scale、shift 或相似变换中的哪些对齐。一个在 affine disparity 协议上表现好的模型，不一定给出形状正确的三维点云。

本章主线：先确定不可观测自由度，再看表示如何减少歧义、条件输入如何补充约束。
本章先给出的答案

尺度来源决定误差能否被新观测纠正。单图 RGB 的 metric 输出依赖学习先验；已知 K 约束射线但不固定物理尺度；可靠的米制深度或基线才增加尺度证据。MoGe 系列分别改善相对形状的学习、尺度与细节的分工、以及局部几何细化，三者收益应拆开评价。

02 / MODEL深度、焦距与尺度，是三个不同的变量

采用 camera-to-world 的 Tᵢ=[Rᵢ,tᵢ]。令像素齐次坐标为 p̃，z-depth 为 z，射线单位向量为 r，则：

Xᶜ = z K⁻¹p̃ = d r，　d = z ‖K⁻¹p̃‖
Xʷ = RᵢXᶜ + tᵢ

将所有 Xʷ 与相机中心乘同一个正尺度，图像投影不变；但固定相机中心只改变深度，不是同一 gauge 变换。已知内参使射线方向确定，通常仍不能恢复绝对尺度；已知 metric baseline 或可信深度则可以约束尺度。

为什么 inverse-depth 的 shift 会改变三维形状？

如果预测逆深度 q 满足 q′=a q+b，则深度为 z′=1/(a/z+b)=z/(a+bz)。b≠0 时，近点与远点受到的缩放不同，不能用一个整体尺度恢复原形状。相反，MoGe 先在点坐标中允许共同 scale 与 shift，再通过投影关系求相机焦距及 z 方向偏移；两种“affine-invariant”不是同一个输出空间。

MoGe 的训练表示也不意味着可以自由旋转、剪切物体。该模型保持图像与 X/Y 轴方向关系，并在中心主点、方形像素假设下求 f 与 t_z。详见 MoGe 方法推导。

尺度评测阶梯。每帧分别对齐 → 全序列共用一个尺度 → 只允许刚体对齐 → 完全不对齐。越靠后越能检验尺度一致性；前一层的优良结果不能代替后一层的实验。

MoGe 的 XYZ 选择，具体换来了什么？

单目 depth 的几何形状需要与 K 一起解释。MoGe 先预测 XYZ，再利用像素—点关系恢复焦距和沿光轴的 shift，改变了求解顺序。其 affine-invariant 目标主要处理统一尺度与平移自由度，并非任意 3×3 仿射形变都可以忽略。全局对齐保持整体形状，局部对齐加强小结构；监督对齐的自由度也说明原始输出并未被要求直接等于米制真值。

从 MoGe 到 MoGe-2，新增尺度分支解决米制读出，训练标签细化改善细节；到 MoGe-3，SSR 引入几何引导的稀疏邻域与学习式迭代。相机恢复、尺度预测、局部细化分别处理不同误差，不能将三代总提升概括成 XYZ 本身的优势。三篇的推导和原图 →

本章结论：关注形状时用对齐后的误差判断；关注量测时检查不对齐的米制误差及尺度来源；关注细节时同时报告局部几何、边界和延迟。这三类目标可能相互取舍。

06 / DISCUSSION把先验、测量与模型信任分开

场景与物体。常见物体的尺寸可能给单目模型提供较强统计线索；房间、街道和未知物体尺度跨度更大。用物体类别先验猜中尺寸，与用传感器约束真实尺度有不同的失效方式。

条件并非总是越多越好。深度和位姿来源可能相关，例如同一个 SfM 系统产生两者。把相关误差当作两条独立证据，会造成过度信任。裁剪图像时若不更新主点，正确内参也会变成错误条件。

建议的拆分。同时记录未对齐 metric error、仅尺度对齐 shape error、焦距误差、边界质量和条件残差。这样才能判断改进来自形状、相机还是整体尺度校正。

07 / RESEARCH可证伪的三个问题

假设控制与干预若出现什么结果则削弱假设
稀疏深度的位置比数量更重要固定测量数和噪声，比较均匀、边界、远近分层采样；报告未对齐误差策略差异在多域重复实验中小于随机方差
软条件融合能识别跨模态冲突分别扰动 K、pose、depth，并加入联合相关偏差；同时看条件残差和置信度错误条件导致大幅偏差但分数不降低
metric 提升主要是尺度而非局部形状对同一预测分别计算未对齐、scale-only 与 scale+shift 指标对齐后的局部误差仍显著降低，则不能仅归因于尺度

以上是本阅读地图提出的实验设计，不是论文已验证的结论。
