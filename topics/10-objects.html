01 / QUESTION完整资产的背面，究竟由谁决定？

场景几何主线通常恢复已观测表面和相机关系。单图物体模型却被期待输出完整可旋转资产，包括从未出现的背面、底部和遮挡区域。这个任务必须借助跨物体先验，或先生成多视图，再用重建器整合成三维表示。

因此本章将 fidelity to observation 与 plausible completion 分开：输入图像是否被准确解释，未见表面是否合理，以及完整资产是否便于编辑、渲染或网格使用，是三个相关但不同的标准。

生成视图可以补充先验，却不会增加真实观测；完整物体也不等于 metric 场景。
本章先给出的答案

单图完整物体的不可见表面由跨物体先验补全。直接重建把先验放在确定性映射中，生成后重建先选择一组可能视图，再整合为三维；两者都没有增加真实观测。输出用 NeRF、Gaussian 还是 mesh 是另一个轴，它影响表面质量与使用成本，而不能独立决定背面是否真实。

02 / MODEL单图到三维先验，两种组织方式

直接重建：I → F → triplanes → (σ(x), c(x)) → mesh
生成后重建：I → {Ĩᵥ, Πᵥ}generated → G / SDF → mesh

LRM 用可学习 triplane queries 从图像 tokens 读取形状与外观，三平面通过坐标投影查询，再由 MLP 解码辐射场。后者先让多视扩散模型选定一个可能的完整物体，再由 LGM 或 InstantMesh 等模块将视图整合。输入的多个生成视图往往相关，不能按真实多视三角化的独立证据处理。

为什么相机归一化会影响形状，而不仅是摆放方向？

单张图像无法独立确定焦距、物距和尺度。LRM 在训练中归一化相机并用相机特征调制 decoder，测试时对任意输入假设固定相机。如果裁剪改变主点或焦距，而模型仍使用原假设，物体纵深和比例可能变形；这不仅是刚体旋转即可修正的问题。

物体评测常将网格平移、缩放到标准盒，再比较 Chamfer / F-score。它检验归一化形状，不检验物理尺寸。InstantMesh 的 F-score 阈值也应在其归一化坐标中解释。

以下比较区分输入条件和可组合的设计轴；收益与代价为机制分析，实验支持范围见证据节。

第一组：未知表面由什么先验决定？

路线收益代价／失败方式输入条件

第二组：三维结果怎样被使用？

输出表示优势几何与工程代价
triplane-NeRF连续查询密度与颜色，适合图像监督和渲染提取表面依赖密度阈值／采样分辨率；mesh 质量与原渲染质量不是同一指标

06 / DISCUSSION物体先验的作用，应在不可见部分承认

确定性单图重建器面对多种可能背面，可能输出平均形状或模糊纹理；扩散生成器可选择一个模式，却仍可能产生前后不一致、重复把手或不正确的薄结构。二者的错误都不能通过“多生成几张图”自动解决。

网格提取又增加了一层误差。NeRF 密度阈值、FlexiCubes 网格分辨率、Gaussian 到表面的转换，都影响最终几何。评测归因时应固定提取器或同时报告原始表示与网格。

若目标是实测物体尺寸或工程部件，必须加入标定、多视观测或外部测量。这里的完整资产主线与场景 metric 几何互有借鉴，但评测目标不同。

07 / RESEARCH测出生成先验究竟帮助了哪里

假设控制实验可证伪条件
生成多视主要改善未见表面对同一物体分可见/不可见区域评估，固定重建器输入可见几何也大幅改变，说明生成误差在反向影响观测
网格监督主要改善表面正则性共享初始化，比较 NeRF/Mesh 的表面噪声、薄结构、CD 与渲染更平滑只是丢失细节，任务相关几何并未改善
相机扰动增强能提升真实照片鲁棒性控制裁剪、FoV、主点误差，固定生成模型只在标准合成相机有效，域外几何仍退化

以上为本地图的可检验假设，不是论文已完成的实验。
