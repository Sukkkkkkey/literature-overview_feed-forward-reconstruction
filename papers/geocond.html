01 / MOTIVATION这一次位姿预测，值得相信或优化吗？

平均精度无法告诉部署系统某个图像对是否病态。GeoCond 在冻结重建骨干上增加轻量适配器，用预测的几何布局估计位姿风险，并决定是否调用昂贵且可能有害的 bundle adjustment。

贡献：把几何条件性变成单次前馈可计算的诊断特征，分开训练误差排序、优化门控和可选位姿修正。

原文依据：§1、§3 · 固定版本 PDF · 原文 HTML

02 / METHOD用几何摘要预测风险

每对图像提取七个标量：parallax、overlap、baseline、relative rotation、camera head 首末更新的旋转/平移差，以及负平均深度置信度；再结合相对姿态的 quaternion 与单位平移方向。小 MLP 分别产生不确定度、BA gate，或可选残差修正。

zij = [geometry summaries, relative pose]
uij=hrisk(zij)，　gij=hgate(zij)
排序、校准与门控为何是三件事？

AUSE 检查移除高风险预测后，剩余误差下降得是否接近 oracle，属于排序能力。要把分数解释成失败概率，还需以独立验证集做 Platt scaling 等校准，并检查域外稳定性。

“误差大”也不等于“BA 能改善”：门控目标是优化后的收益，而不是初始误差。需要分别评估检测错误与选择有效计算的能力。

原文依据：§3.1–3.4；Figure 2 · 固定版本 PDF · 原文 HTML

03 / TRAINING教师成本留在训练，标签来源逐头说明

默认不确定度教师利用 K=6 次输入排列的预测变化，训练适配器后部署只做一次骨干前馈。原文另比较误差监督和独立环路等信号。对严格置换等变的 π³，排列方差会消失，不能照搬同一教师。

不确定度蒸馏可不使用真值误差；BA gate 的标签却来自优化前后位姿误差比较。因此不能把整套方法笼统写成“完全无需真值”。cycle 信号也必须由独立边预测构成，否则从同一组绝对位姿相乘会代数闭合。

原文依据：§3；Tables 3–4；Teacher / gating supervision · 固定版本 PDF · 原文 HTML

04 / EXPERIMENT避免有害优化，不代表超过最优选择

重点读主文 scene-disjoint 混合训练结果；不同教师、训练划分与适配头的表格不能合并。

Table 3 域外结果中，gate 的 pose AUC 为 58.4，高于始终 BA 的 38.4，却仍低于纯前馈 60.3。室内 gate 为 53.5，接近 BA 的 53.6，高于前馈 51.6。这支持选择性优化的价值，也显示门控可能损失一部分原本较好的预测。

适配头约 19.6k 参数，10 对输入的头部耗时约 0.17 ms；完整开销还包括约 3.5 ms 的特征提取以及骨干前馈。不能将 MLP 时间直接称作端到端系统耗时。BA 的秒级代价则另列。

05 / DISCUSSION一致地出错，依然可能看起来可靠

本页分析排列稳定只说明某种输入变换下的稳定性。若模型用相同先验生成相同错误，教师会低估风险。小 baseline、重复结构与分布迁移应按失败类型单独报告，避免总体 AUSE 掩盖局部失效。

研究延伸可将机制分析中的遮挡/对称扰动作为可靠性压力测试，同时记录 risk–coverage、概率校准与计算收益曲线。拒绝或优化的阈值应按应用成本选择，不能由一个平均分数替代。
