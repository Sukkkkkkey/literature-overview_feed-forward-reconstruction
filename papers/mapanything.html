01 / MOTIVATION相机或深度已知一部分时，为什么还要换模型？

真实应用中的已知信息并不固定：有时只有 RGB，有时有标定、部分位姿、稀疏深度，甚至已有局部重建。只接收图像的通用模型难以直接利用这些测量；而为每种组合单独训练模型，又把本来相通的任务重新切开。

MapAnything 用“可选条件输入 + 因子化输出”统一这些设置。它不仅要从外观预测形状，还要区分哪些量只具有相对尺度、哪些输入确实携带米制信息，再把局部观测转换到一个 metric 世界中。

贡献：把射线、沿射线深度、位姿和全局尺度分开建模，使一个模型能利用不同组合的几何先验。

02 / METHOD把“看向哪里”“有多远”“在哪里”分别表示

在本页统一的 c2w 记号下，q 是单位局部射线，ρ̃ 是相对 ray-depth，R、t̃ 为相机到第一相机系的姿态，m 是全局 metric scale：

Ximetric = m [Ri(ρ̃iqi) + t̃i]，　‖qi‖ = 1

局部点图来自 ρ̃q，变换到共同世界系后再整体乘 m。相机位移和形状必须使用同一最终尺度。q 直接描述中心相机的射线，不强制所有射线都由一个针孔 K 生成；它与 DA3 未单位化的世界射线方向不同。

可选输入如何接入

DINOv2 编码 RGB；射线、归一化深度经浅卷积编码；旋转、平移方向与尺度经 MLP 编码。不同模态进入共同维度后求和并归一化。metric 深度或位姿的尺度信息保留并作对数变换；非 metric 输入不假装提供物理单位。

这些 tokens 通过 16 层交替注意力的多视 Transformer，同时加入全局 scale token。第一幅图仍带 reference embedding。DPT 读出射线、相对深度、mask 和 confidence，pose head 读出相机，scale token 经 MLP 输出正的尺度。

需要区分两种归一化

输入时深度和位姿可能各自缺失，故分别归一化；训练输出时要保持跨视图一致性，因此把预测形状与位移共同归一化。这两种操作服务于不同目的，不能把输入阶段的独立尺度误读成输出允许逐视图自由缩放。

03 / TRAINING同时学习“能补什么”和“该信哪些已知量”

训练随机选择可提供的模态和视图子集，覆盖纯图像、已知标定、位姿提示、深度补全等设置。数据混合 metric 与 up-to-scale 标注，因此需要统一几何监督，同时把全局尺度损失单独处理。论文使用 13 个数据集，发布训练数据范围不同的两个模型版本，评测时应记录所用权重。

形状与尺度为什么需要 stop-gradient 分工？
zmetric = m · sg(z̃)

z̃ 来自相对重建的归一化量；sg 表示停止梯度。尺度监督可以更新 m，却不会借这条路径改变形状的归一化因子。形状仍由自己的点图、深度、射线和位姿目标监督。

本页分析：它抑制“形状缩小、scale 变大”的梯度补偿，但共享骨干仍会让任务相互影响，因此不是统计意义上完全独立的形状与尺度模型。

多视采样借助真值深度与位姿预计算共视性，再以随机游走选择连通图像组。这个细节直接影响后续实验可解释性：训练和主测试并不是从任意互不相交图像中凭空恢复关联。

04 / EXPERIMENT条件输入带来的收益，需要单独计账

主评测。ETH3D、ScanNet++ v2、TartanAirV2-WB 的稠密多视评测采样共视连通的图像集合，视图数从 2 到 100。图 4 展示点图、相机、深度、射线和尺度指标；纯 RGB 与附加几何条件使用不同曲线。

先沿同一输入配置比较模型，再看加入条件后的变化。图像 + 内参 + metric 位姿的提升，不能全部归功于“更强视觉表征”，因为模型已得到额外测量。物理尺度误差也不能与对齐后的几何误差相互替代。

单图标定、双图重建和 Robust-MVD 深度实验扩大了适用任务，但它们不使用完全相同的输入与对齐协议。例如表 4 同时列出 metric 和 aligned 设置，阅读时要先判断误差中是否包含尺度错误。

表 5(a) 的纯图像配置中，RDP + Scale 的 pointmap rel 为 0.28、inlier ratio 为 40.7，相比直接 local pointmap + pose 的 0.32、33.2 更好；但 metric scale rel 并非每个配置都最好。这个消融支持因子化及尺度分工的综合价值，不支持“所有子指标一致改善”。

表 5(b) 比较通用与专用训练。通用模型在同样纯图像输入下提高 pointmap inlier ratio；有 metric 深度输入时，pointmap rel 从专用训练的 0.24 变为通用的 0.25，而 inlier ratio 从 53.0 到 54.0。收益是跨任务与训练效率的折中，不能只抄表注中的总括性判断。

实验支持的主线

一个模型能处理多种输入组合，并有效使用辅助几何。因子化表示使其在任务覆盖与几何质量之间取得较好的折中。

仍待检验的条件

评测输入通常是相容、可靠的几何提示。错误内参、有偏深度或互相冲突的传感器提示，是否会被纠正，主文没有给出完整答案。

05 / DISCUSSION“metric”既可以来自测量，也可以来自先验

作者边界论文指出尚未显式建模输入几何的不确定性；没有为全部视图都无图像的条件设计完整接口；动态运动与 scene flow 也不在当前输出中。逐像素绑定的表示还限制了大场景记忆与解码扩展。

本页分析纯 RGB 时的 m 是学习到的尺寸先验，不能消除多视几何的整体尺度歧义；输入可靠 metric 深度或位姿后，才增加了物理尺度约束。比较“metric reconstruction”时必须记录它来自哪个通道。

研究延伸自然的后续实验是向条件加入可控噪声，比较无条件、正确条件、错误条件三组；分别观察形状误差、尺度偏差和条件残差。这个设计比只在理想提示上增加一个输入配置更能检验通用性。
