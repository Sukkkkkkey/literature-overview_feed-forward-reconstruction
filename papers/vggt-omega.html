01 / MOTIVATION几何模型能否沿数据与参数规模持续改善？

VGGT 证明了共享多视骨干的有效性，但高分辨率稠密头、全局 token 交互和高质量三维标注，都使扩大训练变得昂贵。VGGT-Ω 将架构效率与数据管线一起设计：先减少训练成本，再把预算用于更大的模型、更丰富的视频和更可靠的监督。

它保留 VGGT 的主框架，同时重新区分“需要监督的几何量”和“必须直接预测的输出”。多任务监督不必一一对应多个昂贵的稠密头。

贡献：用轻量输出、部分 register attention、高质量视频标注与自监督训练，扩展几何骨干的训练规模。

02 / METHOD缩短稠密读出，把部分交流压到场景 tokens

DINOv3 编码图像，每视图加入一个 camera token 与 16 个 registers。相机与 registers 仍区分参考帧和其他帧，所以该模型没有采用 π³ 的完全无参考设计。

普通 global attention 让各图的全部 tokens 交互；register attention 只在紧凑的场景 tokens 间交换信息，再由 frame attention 把跨图信息传播回图像 tokens。默认仅替换 25% 的 global layers，并没有删除所有全局交互。

删除直接输出，保留几何约束

模型直接输出 depth 与 camera。它简化稠密头，去掉昂贵的高分辨率卷积；相机头仍然存在。pointmap 经反投影派生，匹配监督直接作用于最终 tokens。因此“single dense head”不能改写成“整个模型只有一个头”，也不意味着只监督深度。

P̂ = unproject(D̂, ĝ)
L = λcLcamera + λdLdepth + λpLpoint + λmLmatch

matching loss 拉近同一三维位置对应的归一化 token 特征，并排斥负对；point loss 将深度与相机误差共同暴露在三维空间。深度和相机的分解也适合动态场景，但模型不直接输出运动 mask、scene flow 或有持久身份的轨迹。

为什么 register attention 不等于“全模型线性复杂度”？

设每图 P 个图像 tokens、R 个 registers，共 N 图。普通全局注意力的成对交互数量随 (NP)² 增长；只让 registers 跨图交互，相关项缩为 (NR)²，且 R 远小于 P。

这是常数和参与 token 数的显著改变，但 registers 之间依然可能是全连接；默认模型还保留 75% 的 global layers。因此不能从“部分 register 替换”直接宣称整体对视图数线性。训练／推理中的实际显存也取决于 FlashAttention、激活保存和输出头。

原文依据：§3.1–3.3；原式 (1) · 本地 PDF

03 / TRAINING监督初始化后，再从无标注视频吸收变化

高质量标注管线与保守过滤负责构造可靠几何监督，而不是无差别保留全部视频。主训练采用 supervised → self-supervised → supervised 的阶段安排；模型尺度覆盖 200M、500M、1B、10B。

自监督阶段从已监督训练的 checkpoint 初始化 student 与 EMA teacher。两者看到同一组帧，但接受独立外观增强、旋转、mask 和帧重排；恢复共同排列和对应几何约定后，在特征、深度与相机上施加一致性。相机与深度头冻结以防止退化，教师参数通过指数滑动平均更新。

因此其“self-supervised”是一个训练阶段的属性，不表示整个模型从未使用三维标签。动态视频中的几何监督、原有先验和过滤成本仍是训练方案的重要组成。

原文依据：§3.4–3.5、§4.1；补充标注管线 · 本地 PDF

04 / EXPERIMENT把规模、效率和数据质量分别核对

主评测。三类静态数据（7-Scenes、NRGBD、ETH3D）与三类动态数据（DyCheck、Sintel、TUM-Dynamic），每序列随机采样 10 帧。位姿报告不同阈值的 AUC，深度报告 AbsRel 与 δ₁.₂₅；这些量不衡量持久动态轨迹身份。

图 1 展示模型参数和训练数据增加时的 point error 变化。它支持在作者研究范围内继续扩大训练有效；有限区间中近似平滑的趋势不等于已经证明任何规模下都存在同一条幂律。

训练显存约为前作 30% 的说法不能直接挪到推理。图 7 的推理比较先修正 VGGT 保存全部中间层的实现，只保留预测头需要的四层；同一 A100 80GB / FlashAttention v2 设置下，两者显存接近，Ω 的主要收益表现为速度。不同 patch size 使输入 token 数也不完全相同。

标注质量验证同样有筛选条件：与 MegaSaM 在 Sintel 比较时，排除 8/23 序列以及动态区域，仅在双方都通过过滤的部分评估。较高分数证明保留标签可靠，不能据此推断整个未过滤视频池都同样准确。

实验支持的路线

减少直接稠密输出、保留辅助监督，能把训练预算转移到模型和数据。registers 还可作为下游几何表征，论文有机器人和语言对齐等应用验证。

05 / DISCUSSION将重建看作学习几何表征的训练任务

作者取舍论文指出，加入更复杂的相机迭代或深度头可以继续改善某些指标，但选择优先保持骨干和预测接口简单。它也承认在条件良好时，经典 BA 仍能取得很高的相机精度，前馈输出可以作为后续优化的初始化。

本页分析Ω 的主线不是单个“高效 attention 小技巧”，而是架构、监督与数据扩展的配合。真正可迁移的判断是：哪些信息必须输出成稠密图，哪些只需在特征中受监督，哪些能作为紧凑场景 tokens 服务下游。

研究延伸固定总训练时间比较“多头小数据”和“轻头大数据”，同时报告误差、校准、显存和下游迁移，比仅比较相同迭代数更能检验它的训练效率主张。
