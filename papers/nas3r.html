NAS3R

From None to All: Self-Supervised 3D Reconstruction via Novel View Synthesis

以新视图合成的闭环训练几何，检验无几何标注监督的可行边界。

01 / MOTIVATION用渲染闭环同时学会相机与场景

许多通用重建器依赖大量几何标签；许多无深度标签的 NVS 方法又依赖已知相机。NAS3R 进一步让模型从 RGB 学习相机和 Gaussian 表示，检验 novel view synthesis 能否提供足够的训练约束。

贡献：结合防泄漏的 context / target attention、局部深度到全局的参数化和渐进训练，建立无需几何标签训练的重建闭环。

原文依据：§1、§3 · 固定版本 PDF · 原文 HTML

02 / METHODtarget 提供监督，不能泄漏场景外观

训练同时输入 context 和 target 图像以预测相机，但场景表示只能从 context 获取外观。attention mask 允许 context 读 context，target 读两者；禁止 context 读 target，以免把待预测图像直接写入 Gaussian。

网络先预测局部射线上的正深度，再通过预测相机变换到共同坐标系。与自由回归 canonical XYZ 相比，这限制了 Gaussian 的搜索空间，并将相机与像素位置建立直接关系。第一视图固定参考系；序列内共享内参，并采用主点居中等相机假设。

为什么阻断一条 attention 路径很关键？

若场景表示能看到 target RGB，它可能记住目标外观，再把内容放到某个能重现该图像的位置；此时训练损失低并不说明能够从 context 重建。mask 让重建分支必须依赖上下文，但 target camera 仍可从 target 推断。

即便如此，图像损失仍存在尺度等 gauge 自由度与形状/外观补偿。无几何标签不是无歧义，也不是自动获得米制坐标。

03 / TRAINING初始化与课程使闭环可学习

默认几何骨干随机初始化，相机头从单位姿态和合理焦距起步，context 帧间隔逐渐增大。可微 Gaussian 渲染将 MSE 与 LPIPS 信号回传到相机、深度和外观参数。

“无几何先验”主要指默认配置没有预训练几何骨干和几何标签；LPIPS 本身使用学习到的感知网络。预训练 VGGT / MASt3R 变体，以及使用已知内参的 NAS3R-I，应与默认配置分开。

05 / DISCUSSION闭环自洽与真实几何之间还差什么？

本页分析相机和场景共同预测时，两者可以协同偏移而保留渲染质量。应在不改变训练监督的前提下，用独立几何真值评估相机、深度、表面和尺度，并测试训练域外的内参变化。

适用边界共享内参、中心主点和视频运动分布是有效的结构先验。把相机假设放宽后，优化难度与退化解可能增加；这不削弱方法贡献，但限定了“无几何标签”的外推范围。
