01 / MOTIVATION先找深度，再预测 Gaussian

从多视特征直接回归三维 Gaussian，可能让网络同时承担匹配、三角化和外观表达。MVSplat 将已知相机带来的几何约束显式放进 cost volume，让 Gaussian 中心依附于匹配得到的深度。

贡献：把经典多视立体的深度搜索与可泛化 Gaussian 渲染连接起来，在无需深度真值的训练中获得更直接的几何归纳偏置。

原文依据：§1、§3 · 固定版本 PDF · 原文 HTML

02 / METHOD沿深度候选重投影，比较特征

浅层 CNN 与跨视 Transformer 提取 1/4 分辨率特征。对每张参考图，在逆深度范围采样 128 个候选，根据内参与相对位姿将其他视图特征 warp 到参考像素；点积相似度在其他视图间平均，形成 cost volume。

Ci(p,d) = meanj≠i ⟨Fi(p), Fj(warp(p,d,K,T))⟩
p(d) = softmax(Refine(C))，　D(p)=Σd p(d)d
μw = Rcw[D(p)K⁻¹p̃] + tcw

2D U-Net 和低分辨率跨视 attention 精炼 cost volume，深度期望再经轻量模块细化、上采样。Gaussian 中心由深度反投影；opacity 从匹配概率等特征预测，协方差与球谐颜色另由图像及几何特征预测。每像素对应一个 Gaussian。

cost volume 约束了什么，没约束什么？

它将任意 XYZ 搜索压到已知相机射线上的一维深度搜索，且要求候选在另一视图得到特征支持。相机误差、弱纹理、重复结构或遮挡仍可使正确深度的匹配证据不突出。

最终梯度来自渲染，模型仍可借助形状和 opacity 补偿深度误差。因此“显式 cost volume”提供归纳偏置，并非逐像素几何正确性的保证。

原文依据：§3.1–3.3；Figure 2 · 固定版本 PDF · 原文 HTML

03 / TRAINING没有深度标签，仍有已知相机

训练损失为图像 MSE + 0.05×LPIPS。主配置使用两张上下文、三张目标图像和 256² 分辨率，学习从未见场景构造可渲染表示。特征网络包含预训练初始化，训练与推理都使用相机参数。

主数据集内的训练/测试与 RealEstate10K→ACID / DTU 的零样本迁移分开报告。后者更适合检验几何归纳偏置能否降低对训练域外观的依赖。

原文依据：§4.1；Implementation details · 固定版本 PDF · 原文 HTML

04 / EXPERIMENT最有解释力的证据是移除 cost volume

比较需固定输入相机、上下文数量和分辨率；Gaussian 数量与训练版本也是成本变量。

Table 3 移除 cost volume 后 PSNR 下降超过 3 dB，是显式匹配作用的关键证据。跨视 attention、深度细化等也有独立消融。移除跨视 attention 的版本因过拟合而使用最佳 checkpoint，其他版本使用最终 checkpoint；这会影响消融的严格可比性。

主结果同时覆盖同域 NVS、跨域迁移、几何可视化和运行时间。原文将 encoder 与渲染耗时分开；相对于每像素多个 Gaussian 的路线，较少的基元也影响内存和渲染速度。

05 / DISCUSSION几何结构带来收益，也带来相机依赖

本页分析相机准确时，warp 把匹配问题组织得更清楚；相机偏差会系统性错移 cost volume。可以控制旋转、平移、焦距扰动，分别测深度和渲染退化，判断网络是修复匹配还是用外观表达吸收误差。

适用边界标准模型是静态场景的稀疏视图可渲染重建。动态物体和不可见空间不能由静态匹配假设自动处理。与未知相机方法比较时，要把相机估计纳入输入或系统成本。
