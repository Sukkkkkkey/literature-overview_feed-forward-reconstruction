01 / MOTIVATION单张图像能否直接产生完整物体？

单图不足以观测物体背面。LRM 将问题视为大规模数据学习：用多视物体监督训练一个从单图到三维辐射场的映射，利用跨物体先验补齐未见区域，并减少逐实例优化。

贡献：以 Transformer 连接 DINO 图像特征与 triplane，展示大规模训练支持快速单图物体重建。完整性依赖先验，坐标依赖归一化设定。

原文依据：§1、§3 · 固定版本 PDF · 原文 HTML

02 / METHOD图像 tokens → triplane → 辐射场

DINO 提取图像 patch features。可学习的 3×32² triplane queries 经 16 层 decoder，交替与图像 cross-attention、自身 self-attention 和 MLP，再上采样为 3×64² 三平面特征。相机的外参与内参通过 AdaLN 条件化 decoder。

f(x,y,z)=concat[Pxy(x,y), Pyz(y,z), Pxz(x,z)]
(σ,c)=MLP(f)，　Î(r)=∫ T(t)σ(r(t))c(r(t))dt

任意三维点投影到三个平面，双线性采样后由 MLP 输出密度和颜色。颜色不显式依赖观察方向。可用体渲染生成新视图，也可额外查询密度网格并通过 marching cubes 提取 mesh。

相机条件与物体归一化为什么重要？

单图外观取决于物体与相机的相对关系。若要求网络把任意输入视角统一到物体语义正面，还需识别物体本身的方向。LRM 通过归一化相机，让图像到 triplane 的投影关系更稳定；输出方向与输入视角有关，不是统一语义 canonical pose。

形状在归一化边界内表示，推理时采用假定相机。该设定能产生可用资产，却不能据此恢复现实尺寸；错误焦距也可能变成形状畸变。

原文依据：§3.1–3.2；Figure 1；Appendix D.4 · 固定版本 PDF · 原文 HTML

03 / TRAINING输入单图，监督来自多视物体

训练资料结合大规模 Objaverse 资产渲染与 MVImgNet 物体视频。单张输入，联合监督输入视角及三个侧视角，使用 MSE 与 LPIPS 训练可渲染表示。前景处理、物体缩放和相机归一化都是数据流程的一部分。

部署的一次网络预测只是生成 triplane 的阶段。生成多张新视图、查询高分辨率密度和提取网格另有成本；网格不是原模型直接输出的三角面片。

原文依据：§3.3、§4.1；Appendix C–D · 固定版本 PDF · 原文 HTML

04 / EXPERIMENT规模之外，还要读相机与监督消融

新视角图像质量、背面合理性和真实几何是不同指标；归一化物体实验不能直接迁移为场景米制重建结论。

05 / DISCUSSION背面合理，未必背面真实

原文限制确定性预测容易在未见背面产生平均化纹理；相机假设偏差会影响形状；背景与复杂反光不是当前物体表示的重点。

本页分析单图方法适合检验“观测解释 + 先验补全”。评价应分可见表面、不可见表面与整体资产可用性，避免用感知相似度掩盖几何不确定性。后继多视扩散路线通过生成更多视图补充先验，但生成图像并不是新观测。
