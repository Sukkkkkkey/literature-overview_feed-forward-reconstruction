01 / METHOD · §3让当前几何决定下一轮特征交互

2D 深度边缘看起来清晰，换视角后细栅栏仍可能扭曲。作者将原因之一归于 2D 解码：图像相邻像素可能属于相距很远的前景和背景，却在卷积中混合。MoGe-3 在 MoGe-2 初始化的基础模型后加入 SSR（Self-Guided Sparse 3D Refiner），用预测几何构建稀疏邻域，再逐轮修正。

{{fig:architecture}}

体素坐标与体素特征是两回事

qᵢⱼ = (u,v,ζ) = (X/Z, Y/Z, log Z)
cᵢⱼ(k) = (i,j,round(D·ζᵢⱼ(k)))

q 是每个体素携带的三通道特征；c 才是离散位置。i、j 为像素索引，D 控制 log-depth 分辨率，默认 200。每像素占据一个体素，初始层共 HW 个占据位置。深度不连续处被分离；多尺度下采样仍可在同一图像位置保留不同深度的体素。

这是投影对齐的像素—log-depth 网格，并非均匀欧氏 XYZ 网格。log Z 将尺度乘法变成轴向平移，使离散结构对尺度更稳定；实际仍有取整效应。稀疏 U-Net 在瓶颈注入 DINO 特征，结合外观信息预测残差。

ζ(k+1) = ζ(k) + Δζ(k)，　P(K) = exp(ζ(K))·(u,v,1)

每轮更新后重新体素化，下一轮邻域由新几何决定。u、v 保持不变，仅沿原射线修正深度；这既限制修正自由度，也让跨深度边界的聚合不同于 2D U-Net。默认 K=3，是固定步数的学习式迭代，不是测试时更新网络权重。

训练仍需处理标签质量与初始误差

输出层零初始化，先阻断 refiner 到基础特征的梯度，再联合微调。基础模型接收真实与合成数据，refiner 只从合成样本获得梯度。每轮都监督几何。附录 A.1 还修改了局部损失：随机使用真值或当前预测做多尺度径向分区，各区共享全局尺度、只优化平移。因此三代差异不只是多加一个模块。

03 / DISCUSSION细化强于全局纠错，受初始几何与评测范围约束

本页判断一：参数匹配的 2D 对照支持几何邻域的价值，但还不能证明纯几何就足够：去掉 DINO 注入、只给 RGB 的变体为 49.7%，低于默认 55.1%。外观特征与稀疏结构共同起作用。

本页判断二：固定射线、由当前预测构建邻域，意味着严重初始形状或相机方向错误未必能被修复；这是机制推断，论文未给出覆盖全部此类错误的实验。局部测试又集中在两个合成集，对真实薄结构的泛化还需额外验证。

原文边界：回归模型仍难处理边界像素歧义，会产生飞点。更多迭代在测试范围内趋稳不等于数学收敛保证，也不补足不可见表面或跨帧一致性。

当前预测深度决定稀疏体素的位置和邻接，残差更新后重新构造下一轮邻域；不是用测试图像反向传播来优化模型权重。
