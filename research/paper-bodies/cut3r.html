01 / MOTIVATION场景理解能否随着观察持续积累？

两图模型要通过全局对齐扩展到多图；完整多视模型又可能反复处理历史。CUT3R 选择把过去观察压入持久状态，每帧到来时同时读取历史和写入新内容，使连续三维感知成为一个递归过程。

另一个问题是已观测点以外的场景理解：若状态确实表达了场景，能否用一个虚拟相机查询未见视角？这促使模型区分图像读写与仅用 raymap 的读取。

贡献：双向 state–image 交互、直接局部/世界点图与相机输出，以及持久状态上的新视角几何查询。

02 / METHOD两个 decoder，一边写入一边读取

[z′ₜ,F′ₜ],sₜ = Decoders([z,E(Iₜ)],sₜ₋₁)
F′ₜ → Xself, Xworld, confidence；　z′ₜ → Tₜ

state 是可学习初始化的一组 tokens。每帧由共享 ViT 编码，图像 tokens 与 state tokens 经互联 decoder 交叉注意力交换信息；pose token 负责视图级运动读出。world frame 锚定初始图像。

{{fig:architecture}}

模型同时预测当前相机系点图、世界系点图和 c2w 位姿。理想几何关系是 X_world=T X_self，但模型分别回归这些输出，而非硬性保证恒等。冗余监督使训练能利用部分标签数据。

虚拟相机为何只读取，不更新状态？

给定虚拟相机的 K 与 pose，将各像素的 ray origin 和 direction 拼成六通道 raymap。单独 encoder 将它编码为查询 tokens，经相同的 state-readout 路径预测点图及颜色。raymap 描述“看哪里”，并未带来新的场景观测，因此不应改变已有状态。

未见区域的输出包含跨场景先验。raymap 参数在 metric 坐标中，训练时仅在具有 metric 标注的样本启用该分支，以避免查询坐标与场景尺度不一致。

03 / TRAINING冗余目标允许混合不完整标签

训练混合 32 个数据集，包括静态、动态、室内、室外和物体数据，也能利用只有相机或只有单图深度的样本。点图用置信度加权三维损失，相机用旋转和平移损失，raymap 查询另外监督 RGB。

对于有 metric 真值的数据，采用相同尺度归一化因子以保留真实尺度；无 metric 真值时分别归一化。课程从少视图低分辨率开始，再加入动态与部分标注数据、提高分辨率，最后训练更长序列。原模型 state 为 768 个、每个 768 维的 tokens；这是固定状态容量，不是固定地图输出大小。

05 / DISCUSSION固定容量的状态，怎样面对不断增长的世界？

原文边界长序列可能出现状态容量和尺度漂移问题，动态变化也会挑战同一状态的长期一致性。

本页分析固定 state 节省历史 token 存储，却把场景压缩、遗忘和坐标锚定交给网络。如果静止重复帧不断写入，状态也可能变化；如果离开后回访，旧内容可能已被新场景覆盖。是否能用新证据修正历史输出，取决于系统是否重新读取这些视图。

研究延伸TTT3R 研究冗余观测的更新控制；StreamVGGT 保留历史 KV；ZipMap 将场景写入快速权重。三者提供不同容量与读写规则的对照。
