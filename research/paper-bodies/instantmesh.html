01 / MOTIVATION从可渲染体积走向可用网格资产

单图 LRM 需要独自补齐背面，体积辐射场提取的表面又可能不够平滑。InstantMesh 先用多视扩散生成一组视角，再用稀疏多视重建器预测三维表示，并通过可微网格训练直接改善表面。

贡献：连接多视生成、large reconstruction model 与 FlexiCubes，使单图输入能够较快得到可编辑 mesh。整个流程包含迭代扩散，只有重建器部分是前馈。

02 / METHOD生成视图 → triplane → 可微表面

{{fig:architecture}}

Zero123++ 生成六个已约定相机视角；稀疏多视 Transformer 将图像特征聚合为 triplane。训练先以 NeRF 表示学习，再切换到 SDF、网格顶点变形与 FlexiCubes 权重的预测，利用可微表面渲染细化几何。

s(x)=τ−d(x)
若 d(x)=wᵀh(x)+b，初始化 wSDF=−w，bSDF=τ−b
为什么密度头能初始化 SDF 头？

选择密度阈值 τ 后，d(x)=τ 的等值面对应 s(x)=0。对最后一层做符号与偏置转换，可从已学得的密度表面开始网格训练；但该函数最初不必满足真正 signed distance 的距离性质。

因此转换是一种表面初始化，而不是证明 NeRF 密度天然等价于 SDF。后续可微网格、深度和法向监督才继续塑造几何。

相机条件移入图像特征处理；输出采用 z-up 的 canonical world。相机扰动训练帮助重建器容忍生成视图间的不一致，但不会把生成视图变成严格可靠的测量。

03 / TRAINING两阶段重建，另有生成器适配

从 Objaverse 筛选约 27 万物体，渲染多视 RGB、深度和法向；用六个输入视角及四个监督视角训练。第一阶段使用 RGB、感知与 mask 损失学习 NeRF；第二阶段加入表面深度与法向监督，训练 mesh 表示。

重建器从 OpenLRM 初始化；Zero123++ 另做白背景适配以减少漂浮结构。原文区分 NeRF / Mesh 与 base / large 四种模型，比较前应明确所用变体和输出形式。

04 / EXPERIMENT更平滑、更易用，不代表所有指标更高

GSO 与 OmniObject3D 使用指定采样和归一化对齐。F-score 距离阈值属于归一化空间，不能解释为现实米制精度。
{{fig:experiment}}

Tables 2–4 在 GSO 轨道视角、OmniObject3D 轨道视角和另一组基准视角上，同时比较图像与几何指标。Mesh 版本表面更平滑、适合资产使用，但部分定量指标略低于 NeRF 版本；原文将其与网格表示分辨率限制联系起来。保留这项差异，才能看清表示选择的真实代价。

图像指标中 PSNR、SSIM、LPIPS 不一定一致领先。几何评测会归一化并对齐预测与真值 mesh，再采样点比较，因而它测试的是对齐后的形状，不能检验绝对位置与真实尺度。

05 / DISCUSSION生成的多视图，增加先验而非观测

本页分析六张生成视图可帮助重建器建立更完整的资产，却没有增加关于真实不可见背面的实测信息。应区分生成器的一致性、重建器对给定视图的拟合，以及最终资产对真实物体的忠实度。

可证伪延伸固定同一重建器，分别输入真值视图、生成视图和有控制误差的视图，比较可见/不可见表面误差。若主要差距随生成一致性改善而缩小，瓶颈更可能在多视生成；反之需要检查表示与训练。
